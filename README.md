# Saffron & Ember

A modern restaurant website built with **React 18 + Vite + MUI**.

- Animated hero slider, signature dishes, story, testimonials
- Menu with categories, search and a live order cart (saved in localStorage)
- Table reservation page with a booking summary
- About page with gallery lightbox, contact page with form

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build in /dist
```
